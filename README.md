# The Liban & Fu Show

Independent news, features, commissioned writing, and reader coupons. English and Sinhala.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone https://github.com/ahazfernando/lubonandfushow.git
cd lubonandfushow
npm i
npm run dev
```

## Scripts

- `npm run dev` — start the Next.js dev server
- `npm run build` — production build
- `npm run start` — serve the production build
- `npm run lint` — ESLint
- `npm run format` — Prettier

## Built with

- Next.js
- TypeScript
- React
- Tailwind CSS
